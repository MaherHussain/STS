# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0-beta.1] - 2026-04-20

### Added
- **Initial release** of the Shift Tracking System (STS).
- **Role-Based Access Control**: Specialized dashboards for both Admins and Employees.
- **Workforce Management**: Support for multiple pay types, including `HOURLY` pay and `REVENUE` share models.
- **Shift Logging**: Simplified shift logging with template support and explicit date selection.
- **Evidence Proofs**: Secure image proof storage and management via Cloudinary integration.
- **Mobile-First Design**: Fully responsive UI optimized for performance on mobile devices.
- **Admin Insights**: Comprehensive dashboard for monitoring employee logs, earnings, and system stats.
- **Quality Assurance**: Integrated End-to-End (E2E) testing with Playwright and unit testing with Vitest.
